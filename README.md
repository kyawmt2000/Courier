# Blink Delivery Download Site

Static website for distributing the official Blink Delivery Android APK.

## Update the APK

Place the signed Android APK here:

```text
downloads/blink.apk
```

The homepage download button points to `/downloads/blink.apk`.

## Deploy on Render

Use this project as a Render Static Site.

```text
Build Command: npm run build
Publish Directory: dist
```

The included `render.yaml` has the same settings for Render Blueprint deploys.
